Button ​

基础 ​

基础按钮分为default、primary、info、success、warning、danger。

<script setup>
  import Button from "../src/button.vue";
  /**
   * Demo: 基础
   *
   * 基础按钮分为`default`、`primary`、`info`、`success`、`warning`、`danger`。
   */
</script>
<template>
  <div class="flex-x-center gap-4">
    <Button>default</Button>
    <Button class="btn-primary">primary</Button>
    <Button class="btn-info">info</Button>
    <Button class="btn-success">success</Button>
    <Button class="btn-warning">warning</Button>
    <Button class="btn-danger">danger</Button>
  </div>
</template>

镂空风格 ​

在类型类名的后面添加-ghost后缀，即可转换为镂空风格。

如：btn-primary-ghost

<script setup>
  import Button from "../src/button.vue";
  /**
   * Demo: 镂空风格
   *
   * 在类型类名的后面添加`-ghost`后缀，即可转换为镂空风格。
   *
   * 如：`btn-primary-ghost`
   */
</script>
<template>
  <div class="flex-x-center gap-4">
    <Button class="btn-ghost">default</Button>
    <Button class="btn-primary-ghost">primary</Button>
    <Button class="btn-info-ghost">info</Button>
    <Button class="btn-success-ghost">success</Button>
    <Button class="btn-warning-ghost">warning</Button>
    <Button class="btn-danger-ghost">danger</Button>
  </div>
</template>

边框风格 ​

使用btn-dashed可以将边框改为虚线。

可在组件的父元素上添加btn-dashed，这样子按钮们都会应用虚线边框。

<script setup>
  import Button from "../src/button.vue";
  /**
   * Demo: 边框风格
   *
   * 使用`btn-dashed`可以将边框改为虚线。
   *
   * 可在组件的父元素上添加`btn-dashed`，这样子按钮们都会应用虚线边框。
   */
</script>
<template>
  <!--可在在父元素上添加 btn-dashed 这样所有的子按钮都变为虚线-->
  <div class="btn-dashed flex-x-center gap-4">
    <!--或直接在按钮组件上添加 btn-dashed，这样只作用于按钮本身-->
    <Button class="btn-ghost btn-dashed">default</Button>
    <Button class="btn-primary-ghost btn-dashed">primary</Button>
    <Button class="btn-info-ghost">info</Button>
    <Button class="btn-success-ghost">success</Button>
    <Button class="btn-warning-ghost">warning</Button>
    <Button class="btn-danger-ghost">danger</Button>
  </div>
</template>

按钮尺寸 ​

尺寸分为xs、sm、md、lg、xl，默认为md。

完整尺寸类名：btn-xs|sm|md|lg|xl，如：btn-md。

<script setup>
  import Button from "../src/button.vue";
  /**
   * Demo: 按钮尺寸
   *
   * 尺寸分为`xs`、`sm`、`md`、`lg`、`xl`，默认为`md`。
   *
   * 完整尺寸类名：`btn-xs|sm|md|lg|xl`，如：`btn-md`。
   */
</script>
<template>
  <div class="flex-center gap-4">
    <Button class="btn-primary btn-xs">primary</Button>
    <Button class="btn-primary btn-sm">primary</Button>
    <Button class="btn-primary btn-md">primary</Button>
    <Button class="btn-primary btn-lg">primary</Button>
    <Button class="btn-primary btn-xl">primary</Button>
  </div>
</template>

按钮形状 ​

等高宽：在尺寸的前面添加前缀-size来将按钮设置成等高宽，如：btn-size-md （尺寸默认为md，可省略为btn-size）。

圆形：在尺寸的前面添加前缀-size并添加后缀-round,即可设为圆形，例如：btn-size-md-round。

两边圆：在尺寸后面添加-round，如：btn-md-round。

<script setup>
  import Button from "../src/button.vue";
  /**
   * Demo: 按钮形状
   *
   * 等高宽：在尺寸的前面添加前缀`-size`来将按钮设置成等高宽，如：`btn-size-md` （尺寸默认为`md`，可省略为`btn-size`）。
   *
   * 圆形：在尺寸的前面添加前缀`-size`并添加后缀`-round`,即可设为圆形，例如：`btn-size-md-round`。
   *
   * 两边圆：在尺寸后面添加`-round`，如：`btn-md-round`。
   */
</script>
<template>
  <div class="flex-x-center gap-4">
    <Button class="btn-primary">默认的圆角</Button>
    <Button class="btn-primary btn-round">两边的圆角</Button>
    <Button class="btn-primary btn-size-md">正</Button>
    <Button class="btn-primary btn-size-md-round">圆</Button>
  </div>
</template>

加载状态 ​

<script setup>
  import { ref } from "vue";

  import Button from "../src/button.vue";
  /** Demo: 加载状态 */
  let isLoading = ref(false);

  function handleClick() {
    isLoading.value = !isLoading.value;
  }
</script>
<template>
  <div>
    <Button class="mb-4" @click="handleClick">加载{{ isLoading }}</Button>
    <div class="flex-x-center gap-4">
      <Button :loading="isLoading">default</Button>
      <Button class="btn-primary" :loading="isLoading">primary</Button>
      <Button class="btn-info-ghost btn-dashed" :loading="isLoading">info</Button>
      <Button class="btn-success-ghost" :loading="isLoading">success</Button>
      <Button class="btn-warning-text" :loading="isLoading">warning</Button>
      <Button class="btn-danger-ghost" :loading="isLoading">danger</Button>
    </div>
  </div>
</template>

禁用按钮 ​

在组件上使用的设置属性disabled将按钮设置为禁用。

<script setup>
  import Button from "../src/button.vue";
  /**
   * Demo: 禁用按钮
   *
   * 在组件上使用的设置属性`disabled`将按钮设置为禁用。
   */
</script>
<template>
  <div class="flex-x-center gap-4">
    <Button disabled>default</Button>
    <Button class="btn-primary" disabled>primary</Button>
    <Button class="btn-info-ghost" disabled>info</Button>
    <Button class="btn-success-text" disabled>success</Button>
    <Button class="btn-warning-soft" disabled>warning</Button>
    <Button class="btn-danger-ghost btn-dashed" disabled>danger</Button>
    <Button class="btn-danger-soft" disabled>danger</Button>
  </div>
</template>

ButtonProps ​

名称类型默认值说明
disabled?boolean是否禁用
icon?string图标
iconPlacement?"left"|"right""left"图标显示的位置
loading?boolean是否显示loading状态

ButtonEmits ​

名称类型说明
click(e:Event)点击事件

ButtonSlots ​

名称说明
icon-left左边的图标
default默认插槽
icon-right右边的图标
loading加载的插槽
